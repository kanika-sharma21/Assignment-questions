○ Assignment Questions Portal

A frontend web application developed as part of my BCA (Hons.) Web Programming coursework.
This project allows assignments to be posted, viewed, edited, and deleted using a simple admin panel.

○ Features
- View all assignment questions in a clean UI
- Admin panel with password protection
- Add, edit, and delete assignments
- Data stored using Firebase Realtime Database
- Fallback to browser localStorage if Firebase is unavailable
- Responsive design for mobile and desktop

○ Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Firebase Realtime Database
- Netlify (Deployment)

○ Admin Access
- Admin password is required to post, edit, or delete assignments
- (Password is hardcoded for educational purposes only)
